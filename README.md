# PulseFX v1.2 (Fabric 1.21.11)
All effects use custom animated sprites (no vanilla particles): pixel wings, bubbles, stars, sakura, flames, runes, rings.
Sprites live in src/main/resources/assets/pulsefx/textures/particle - replace any PNG to restyle an effect.
Push to GitHub -> Actions tab -> latest "build" run -> Artifacts -> PulseFX-jar. Menu key: P.
Needs Fabric Loader + Fabric API in the game.
